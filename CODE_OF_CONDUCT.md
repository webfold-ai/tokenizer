# Code of conduct

## Our commitment

This project is a place to do careful work on a small piece of software. Everyone is welcome to
participate, regardless of experience, background, identity or affiliation. What is expected is
technical honesty and ordinary courtesy, not agreement.

## What is expected

- **Argue with the code, not the person.** "This is wrong because the round trip fails on a
  mid-character boundary, here is the input" is the standard; anything aimed at the author is not.
- **Assume the other person read the source.** If they did not, point at the line.
- **Say when you do not know.** A wrong guess presented as fact costs more here than an open
  question.
- **Respect the scope.** A pull request that changes something the maintainer did not ask for may be
  declined without a debate about its merits.

## What is not tolerated

Harassment, insults, discriminatory language, sexual attention, doxxing, sustained disruption of
discussion, and publishing someone's private information. This applies in issues, pull requests,
commit messages, code comments and any project space.

## Enforcement

Report a problem privately to the maintainer (see `SECURITY.md` for the private channel; the same
address reaches a human for conduct reports). Reports are read by the maintainer, kept confidential,
and answered within 7 days.

Responses, in order of severity: a private word; a request to edit or delete the offending content;
a temporary block from the repository; a permanent block. The maintainer decides, and says which
response was taken and why.

## Scope

This code applies to project spaces (issues, pull requests, discussions, commit messages) and to
public spaces when someone is representing the project.

## Attribution

The structure follows the Contributor Covenant (version 2.1), rewritten for this repository's size
and scope.
